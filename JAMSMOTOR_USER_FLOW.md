# User Flow Jamsmotor

Artefak utama berada di:

`public/jamsmotor-user-flow.svg`

## Cara menggunakan di FigJam

1. Buka board FigJam tujuan.
2. Drag file `jamsmotor-user-flow.svg` ke canvas, atau gunakan menu **Place image**.
3. Letakkan diagram dalam section bernama **User Flow Website Jamsmotor**.
4. Jika tim perlu mengedit setiap node secara terpisah, gunakan diagram sebagai acuan lalu buat ulang node dengan shape dan connector FigJam.

## Struktur diagram

Diagram dibagi menjadi tiga swimlane:

1. **Eksplorasi Mobil** — halaman utama, katalog, filter, hasil pencarian, dan detail kendaraan.
2. **Evaluasi & Keputusan** — penjelasan varian, promo, simulasi kredit, konsultasi, dan test drive.
3. **Tindak Lanjut Sales** — estimasi kredit, komunikasi sales, validasi form, dan konfirmasi test drive.

## Legenda

- Biru: aktivitas calon pembeli di website.
- Kuning: keputusan atau percabangan.
- Hijau: hasil akhir atau kondisi sukses.
- Merah muda: error atau empty state.
- Abu-abu: aktivitas sales di luar website.

## Batasan cakupan

Pembayaran, pengelolaan stok, dan sistem administrasi internal tidak dimasukkan karena berada di luar kebutuhan yang dijelaskan.
